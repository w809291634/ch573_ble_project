# 模块应用实例说明 — bitsops（位操作工具）

> 文档版本：v0.2.8　对应代码：当前目录（`bits_ops.c` / `bits_ops.h`）
> 框架入口：[../../../README.md](../../../README.md)

## 场景一：单个状态字

```c
#include "bits_ops.h"

static bitsop_t flags = BITSOP_INIT(0);

void set_ready(void)
{
    bitsop_set_bit(&flags, 0);
}

int consume_ready(void)
{
    return bitsop_test_and_clear_bit(&flags, 0); /* 1 表示此前已就绪 */
}
```

预期：首次调用 `consume_ready()` 返回 1，后续调用返回 0，适合事件循环中的“一次性消费”状态。

## 场景二：多位位图

```c
BITSOP_DEFINE(channels, 64);  /* 至少 64 个 bit */

void enable_channel(int channel)
{
    bitsop_set_bit(channels, channel);
}
```

接入步骤：将 `bits_ops.c` 编入工程、将本目录加入包含路径，并用 `BITSOP_DEFINE` 声明足够的位数。
预期：`enable_channel(63)` 会设置第二个 32 位字中的第 31 位。该实例适用于单线程或调用方已完成同步的
上下文；中断/任务并发共享状态应改用 `atomic` 或平台同步机制。


## 接入步骤

1. 将 `bits_ops.c` 加入工程源，把本目录加入包含路径。
2. 声明状态目标：单个 `bitsop_t`，或 `BITSOP_DEFINE(name, nbits)` 声明跨字位图。
3. 在单线程或调用方已同步的上下文按需调用 `bitsop_*`。
4. 验证：运行 `test/host_unit_test/test_bits_ops.c` 覆盖的用例做回归。
