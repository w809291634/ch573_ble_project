# 模块功能与接口说明 — bitsops（位操作工具）

> 文档版本：v0.2.8　对应代码：当前目录（`bits_ops.c` / `bits_ops.h`）
> 框架入口：[../../../README.md](../../../README.md)

## 功能与限制

`bitsops` 提供 32 位值的比较交换、算术、读写、逻辑位运算和位图辅助函数。类型为 `bitsop_t`/
`bitsop_val_t`（`uint32_t`）；`BITSOP_DEFINE(name, num_bits)` 可声明跨多个 32 位字的位图。

本模块在 `apl_inputex` 的单线程扫描上下文中用于维护状态位和掩码。它不包含临界区接口：在无编译器
原子实现或存在中断/多任务共享时，调用方不得把它当作并发保护；此类场景应使用同级 `atomic` 模块或
工程同步原语。

**适用范围**：单线程状态机、非并发位图和已由调用方完成同步保护的状态字。
**不适用范围**：中断与任务、多个任务或多个核同时读改写同一地址的并发保护。
**资源与限制**：基础类型固定为 32 位；`BITSOP_DEFINE` 按 32 位自动扩容。除调用方声明的位图外，
模块不分配全局 RAM、不维护状态，也没有运行期配置项。

## API

| 类别 | API |
| --- | --- |
| 值操作 | `bitsop_cas`、`bitsop_add/sub/inc/dec/get/set/clear` |
| 逻辑操作 | `bitsop_or/xor/and/nand` |
| 位操作 | `bitsop_test_bit`、`bitsop_test_and_clear_bit`、`bitsop_test_and_set_bit`、`bitsop_clear_bit`、`bitsop_set_bit`、`bitsop_set_bit_to` |
| 宏 | `BITSOP_INIT`、`BITSOP_DEFINE` |

除 `bitsop_cas` 返回成功/失败外，修改值的 API 均返回修改前的值；位测试/测试并修改 API 返回该位的旧状态。
位编号从 0 开始，数组位图按每 32 位自动定位。

调用方须保证目标地址有效且按 `bitsop_t` 对齐；位图型 API 的目标数组必须由 `BITSOP_DEFINE` 或等价的
足够空间声明提供。无配置项，故本模块的配置项说明为 N/A。

## 调用约定（前置条件与上下文）

- 前置条件：目标地址有效且按 `bitsop_t`（4 字节）对齐；位图型 API 的目标数组由 `BITSOP_DEFINE` 提供足够空间。
- 上下文：单线程或调用方已同步的上下文。本模块不保护关键区；被中断/任务并发读改写时改用 `atomic`。
- 返回值：修改值的 API 返回**修改前**值；`bitsop_cas` 返回是否写入成功；位测试/修改返回该位修改前的状态。
- 头文件：`#include "bits_ops.h"`；除本目录外无第三方包含路径依赖。
- 配置项说明：本模块无编译期与运行期配置项（N/A）。
