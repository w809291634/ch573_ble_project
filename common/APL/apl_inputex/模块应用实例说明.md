# 模块应用实例说明 — apl_inputex（通用输入）

> 文档版本：v0.2.8　对应代码：当前目录（`apl_input.c` / `apl_input.h`）
> 配套工程：`../../../test/ESP32s3_apl_inputex_test/`、`../../../test/STM32F103_apl_inputex_test/`、`../../../project/ESP32s3_example/`

## 1. 典型场景

### 场景一：短按 / 长按 / 超长按（单键模式，`BOARD_CONFIG_EN_INPUT_MASK==0`）
- **输入**：单个按键 GPIO，内部上拉，低电平有效。
- **配置**：3 级超时 `T0=25ms`（去抖/短按确认）、`T1=1000ms`（长按）、`T2=5000ms`（超长按）。
- **流程**：短按（按住 <1s 松开）→ 上报 `INPUT_EV_SINGLE_DOWN (level=0)`；长按（≥1s）→ `level=1`；超长按（≥5s）→ `level=2`；松开 → `INPUT_EV_SINGLE_UP`。
- **预期结果**：应用按 `ev->level` 依次触发"单击计数 / 长按调速 / 超长按进入设置"。单次 hold 只上报一次，不重复。

### 场景二：组合键手势（组模式，`BOARD_CONFIG_EN_INPUT_MASK==1`）
- **输入**：4 路按键（复位示例工程 `KEY_1..KEY_4`）。
- **配置**：时间表 `T0=25`、`T1=1000`、`T2=5000`；组模式开。
- **流程**（对应 `test/ESP32s3_apl_inputex_test/app/app.c`）：
  - `KEY1+KEY2` 按住 1s（T1）→ `INPUT_EV_COMBO_DOWN, level=1, mask=0x03` → 亮度连续加；
  - `KEY3+KEY4` 按住 5s（T2）→ `level=2, mask=0x0C` → 亮度连续减；
  - `KEY1+KEY4` 按住 1s → `mask=0x09` → 老化模式；
  - 以上全部松开 → `INPUT_EV_COMBO_UP` → 关闭对应功能。
- **预期结果**：组合按下只上报一次；`elapsed_ms` 给出 hold 时长，应用据此处理"已持续 N 秒后再动作"语义。

## 2. 接入步骤（从零接入）

1. **依赖**
   - 软件：C11 编译器（GCC 或 Keil MDK/ARMCC 皆可）；目标板需提供毫秒时基接口（ESP-IDF 用 `esp_timer`，STM32 用 SysTick/定时器中断）。
   - 硬件：按键 GPIO、去抖（模块内软件去抖，通常不用外部 RC）。
2. **拷贝模块**：将 `common/APL/apl_inputex/` 与 `common/UTILS/bitsops/` 加入工程包含路径与编译源。
3. **配置**：在 `board/board_config.h` 定义三个宏——
   ```c
   #define BOARD_CONFIG_INPUT_OBJS_NUM         N      /* N=按键路数 */
   #define BOARD_CONFIG_INPUT_TOUT_EVT_NUM     3      /* T0/T1/T2 */
   #define BOARD_CONFIG_EN_INPUT_MASK          1U     /* 1=组模式 */
   ```
   并在 `app/app.c` 提供 `uint32_t board_now_ms(void)` 作为时基。
4. **初始化**：构造 `input_mgr_cfg_t`，调用 `Input_Mgr_InitEvent(&cfg)`，检查返回值是否为 0。
5. **周期调用**：在主循环/任务中按固定周期（如 ≤ timeout[0]）调用 `Input_Scan()`。
6. **业务回调**：实现 `input_event_cb_t`（`app_input_event`），按 `evt / level / mask` 分发动作。
7. **验证**：
   - 主机侧：`& .\test\host_unit_test\run.ps1`（PASS）；
   - 目标板侧：烧录示例工程，按 README 预期串口日志比对。

## 3. 示例代码（与当前 API 一致，可编译，含错误处理）

组模式、2 路按键（KEY_A=index0、KEY_B=index1），毫秒时基 `board_now_ms` 由工程提供。

```c
#include "apl_input.h"
#include "board_config.h"
#include <string.h>

extern uint32_t board_now_ms(void);     /* 毫秒时基接口 */

/* 工程/平台层：读电平回调（返回 1=激活） */
static int key_read(uint32_t index)
{
    /* 示例：低电平有效，按下返回 1 */
    /* return (gpio_get_level(key_pin[index]) == 0) ? 1 : 0; */
    return 0;
}

/* 工程/平台层：键值扫描钩子（可选，NULL 亦可） */
static int key_scan(void* user)
{
    (void)user;
    return 0;
}

/* 统一事件回调：组合按下/抬起、单键按下/抬起全在此收敛 */
static int app_input_event(const input_ev_t* ev, void* user)
{
    (void)user;
    switch (ev->evt) {
    case INPUT_EV_COMBO_DOWN:
        /* 组合按下：按 level/mask 分派业务 */
        if (ev->level == 1U && (ev->mask & 0x03U) == 0x03U) {
            /* KEY_A+KEY_B 按住 1s：亮度连续加 ON */
        }
        break;
    case INPUT_EV_COMBO_UP:
        if (ev->level == 1U && (ev->mask & 0x03U) == 0x03U) {
            /* 松开：亮度连续加 OFF */
        }
        break;
    case INPUT_EV_SINGLE_DOWN:
    case INPUT_EV_SINGLE_UP:
        break;
    default:
        break;
    }
    return 0;
}

void app_input_init(void)
{
    input_timout_t t = { { 0 } };
    t.timeout[0] = 25U;     /* T0：去抖/短按确认 */
    t.timeout[1] = 1000U;   /* T1：长按 1s（组合在此级判定） */
    t.timeout[2] = 5000U;   /* T2：超长按 5s */

    input_mgr_cfg_t cfg = {
        .get_ms   = board_now_ms,   /* 毫秒时基 */
        .scan     = key_scan,       /* 键值扫描钩子 */
        .event_cb = app_input_event,/* 统一事件回调 */
        .timout   = &t,             /* 超时时间表 */
        .read     = key_read,       /* 读电平 */
        .obj_num  = 2U,             /* KEY_A / KEY_B */
    };

    /* 错误处理：初始化失败直接返回 */
    if (Input_Mgr_InitEvent(&cfg) != 0) {
        /* log_e("input init failed"); */
        return;
    }
}

void app_input_poll(void)
{
    Input_Scan();   /* 主循环周期调用，例如 5ms */
}
```

> 该示例与 `test/ESP32s3_apl_inputex_test/app/app.c` 同构（后者为 4 键组模式完整版），可作为接入模板直接套用。


### 场景三：多任务 / RTOS 环境

`apl_inputex` 为单线程轮询模型，状态为静态全局，未内置临界区。在 RTOS 中应放入**单一任务**周期调用：

- 由该任务完成 `Input_Mgr_InitEvent()` 与后续 `Input_Scan()`；
- 事件回调在扫描任务上下文同步执行，业务应尽快返回，不做长时间阻塞；
- 若中断或其它任务需要读取输入状态，请经 `atomic`/事件队列等由工程层同步，不要直接访问 `input_mgr_t` 内部状态。
